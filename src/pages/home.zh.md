# 18xx Maker

18xx Maker 可以读取以 json 编写的 18xx 游戏定义,将其显示出来,并渲染成可供打印的内容。本站最初是为个人自制(Print and Play)项目而设计的,但随着时间推移,它的用途已经转向新游戏的原型设计。

::: siteonly

> [!TIP]
> 我们还提供了打包成[桌面应用](https://github.com/18xx-maker/18xx-maker/releases)的 18xx Maker。界面相同,但对文件编辑有更好的支持,并提供更多导出选项。如果您正在为自己的游戏制作原型,我们强烈建议您下载该应用。

:::

## 统计分析

18xx Maker 使用自行托管的 [Plausible](https://plausible.io/) 来收集一些统计数据。我们不会收集任何个人数据,也不会收集您使用和编辑了哪些游戏或文件。唯一目的是了解用户如何访问 18xx Maker 以及哪些功能被使用,以便我们把精力放在更有价值的地方。这些统计数据[公开可查](https://analytics.18xx-maker.com)。
