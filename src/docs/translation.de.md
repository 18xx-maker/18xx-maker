# Übersetzungen von 18xx Maker

Die Benutzeroberfläche und die Dokumentation dieses Tools können in andere
Sprachen übersetzt werden. Wenn du bei einer Übersetzung helfen kannst, melde
dich bitte bei uns!

## Maschinelle Übersetzungen

Die deutschen (`de`) und vereinfacht-chinesischen (`zh`) Übersetzungen der
Benutzeroberfläche und aller Dokumentationsseiten wurden von einer KI erstellt,
nicht von Muttersprachlern, und können daher Fehler oder ungeschickte
Formulierungen enthalten, besonders bei Begriffen aus 18xx und Brettspielen
(Plättchen, Token, Gesellschaftskarten, Par und so weiter). Pull Requests, die
sie korrigieren, sind sehr willkommen, ob es sich um ein einzelnes Wort oder
eine ganze Datei handelt.

## Benutzeroberfläche

Die maßgebliche Quelle für die Übersetzungen der Benutzeroberfläche ist die
Hauptdatei
[src/locales/en.json](https://github.com/18xx-maker/18xx-maker/blob/main/src/locales/en.json).
Wenn du eine Übersetzung in eine andere Sprache erstellen möchtest, reiche
einfach einen Pull Request mit diesem Inhalt in der anderen Sprache ein.

## Dokumentation

Die Dokumentationsseiten (einschließlich dieser) liegen als
[Markdown](https://www.markdownguide.org/)-Dateien [im
Repository](https://github.com/18xx-maker/18xx-maker/tree/main/src/docs). Die
Dateinamen haben das Format `<slug>.<language>.md`. Die `en`-Dateien gelten als
maßgebliche Quelle. Um weitere Sprachen hinzuzufügen, reiche bitte einen Pull
Request mit weiteren Sprachdateien ein.
