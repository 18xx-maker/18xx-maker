# 使用 18xx Maker

你好!这里是 18xx Maker 的文档部分。希望我们能帮助您很快上手并创建游戏原型。本页介绍两种常见的使用场景。更多信息请浏览左侧站点菜单中的其他文档。

初次使用?请跟着[第一款游戏教程](/docs/games/first-game)操作,常见问题请参阅[常见问题](/docs/faq)。

> [!TIP]
> 这些文档介绍的是如何使用 18xx Maker。如果您有兴趣修改代码或在本地运行代码,请参阅代码仓库中的
> [DEVELOPMENT.md](https://github.com/18xx-maker/18xx-maker/blob/main/DEVELOPMENT.md)。

## 打印游戏

打印游戏最简单的方法是在网站上浏览到您想打印的组件,然后直接用浏览器打印该页面。页面会按当前所有配置设置和选项打印。

例如,如果您想打印 [Shikoku 1889](/games/1889) 的分页地图,请浏览到[地图页面](/games/1889/map),然后打开工具栏左上角的“分页”开关(也可以直接打开[分页地图](/games/1889/map?paginated=true))。接着在浏览器菜单中选择“打印”即可。

打印出来的游戏不包含页面上的任何界面元素。您也可以使用系统的直接打印为 PDF 文件的功能。网站默认使用 US Letter 尺寸的纸张来打印分页内容。您可以在网站的配置中更改(这些设置是全局的,不是针对单个游戏的)。如果要打印不分页的组件,您需要在系统的打印对话框中正确设置纸张尺寸以便适配。否则操作系统会自行对其分页(效果不佳)。

> [!TIP]
> 请务必看看[配置面板](?config=true)。它可以让您自定义游戏的显示和打印方式。我们提供了许多配色主题!

### 从 18xx Maker 应用导出

使用[应用](https://github.com/18xx-maker/18xx-maker/releases)时,每个游戏页面工具栏的左上角都有一个按钮(位于“分页”开关旁边):

![带有导出按钮的游戏页面工具栏](/images/export-button.png)

它的菜单包含以下条目:

- 将游戏导出为 PDF 文档
- 将游戏导出为 PNG 图片
- 将游戏导出为 Board18 游戏盒
- 导出选项

导出整个游戏的条目会要求您在文件系统中选择一个文件夹,并把所有文件写入其中。完成后应用会打开该文件夹。Board18 条目会在文件夹中放入一个 zip 文件以及其中的文件。如果只想导出一个页面,请使用_导出选项_并选择您需要的文档。

导出过程中会显示进度提示。从_导出选项_面板启动的完整导出可以在该面板中取消;已经写入的文件会保留。如果某个文档无法导出,其他文档仍会写入,提示中会显示第一个错误。

#### 导出选项

_导出选项_条目会打开一个面板,让您精确选择完整导出要生成的内容:

- **格式**:PDF 文档、PNG 图片和 Board18 游戏盒,可任意组合。
- **文档**:要导出哪些页面(地图、地块、卡牌、标记等),适用于 PDF 和 PNG 文件。
- **页面的每一种布局**:为卡牌、地块和标记的每一种布局各生成一个文件,而不是只生成您配置中的那一种布局。
- **地图变体**:导出某一个变体或全部变体,适用于有多张地图的游戏。
- **PNG 分辨率**:1 到 300 dpi。300 是默认值,也是最大值。
- **Board18 版本和作者**:用于 Board18 游戏盒。

该面板的初始值取自游戏文件的 `exports` 字段(参见[导出选项](/docs/games/exports)),因此您分享的游戏可以按其作者的意图导出。您可以只为本次导出更改面板中的任何内容,也可以使用_重置为游戏的选项_恢复。这些选项同样是命令行 `maker export` 的参数。

导出使用与您所见页面相同的配置(包括游戏自身的配置和您保存的布局设置),但无论应用使用什么主题,始终以浅色主题渲染。文件以游戏的标题命名。

#### PNG 图片

PNG 图片默认以 300 dpi 生成,这是打印时使用的分辨率,并且图片会带有该分辨率信息,因此一张卡牌在图像编辑器或打印程序中打开时会是它的实际尺寸(2.5 × 3.5 英寸)。您可以在面板中选择更低的分辨率,或在游戏文件的 `exports` 中使用 `png.dpi`。Board18 游戏盒中的图片无论分辨率如何,始终每个单位使用一个像素。

## 创建新游戏

> [!NOTE]
> 目前 18xx Maker 不支持在网站或应用中编辑游戏文件。我们正在开发这项功能。

创建新游戏最快的方法,是从与您想制作的游戏相近的[游戏文件](https://github.com/18xx-maker/18xx-maker/tree/main/src/data/games)入手。

有了游戏文件之后,您可以把它拖入浏览器窗口(或在站点任意位置按 `o` 键),将该游戏文件加载到浏览器中。根据浏览器的不同,我们要么把游戏复制到浏览器中,要么直接使用您文件系统中的文件。在网站上,您修改后需要重新加载游戏,或在工具栏中选择“刷新”。如果您使用的是 18xx Maker 应用,每次您编辑 JSON 文件时,应用都会自动重新加载。

若要在加载前检查游戏文件是否有错误,请运行 `pnpm maker validate my-game.json`(参见[文件](/docs/files))。

了解 JSON 文件中有哪些可用内容是个不太容易的过程。请多利用[元素](/elements)页面,查看地块或地图六边格上可以做的大部分事情。目前第二好的资源是到 [Discord](https://discord.gg/gcYvAjYYfw) 里提问。

## 快捷键

在网站或应用中使用 18xx Maker 时,可使用以下快捷键:

| 按键                 | 用途                           | 备注                                 |
| -------------------- | ------------------------------ | ------------------------------------ |
| `a`                  | 前往基础元素页面               | 不适用于游戏编辑页面                 |
| `c`                  | 前往标志页面                   | 不适用于游戏编辑页面。编辑时切换配置 |
| `e`                  | 在第一个部分编辑已加载的游戏   | 在游戏编辑页面上,返回游戏页面        |
| `m`、`1` 到 `9`、`0` | 在地图或某个部分编辑已加载游戏 | 仅在已加载游戏时可用                 |
| `Esc`                | 返回游戏页面                   | 仅在游戏编辑页面可用                 |
| `g`                  | 前往游戏页面                   | 仅在已加载游戏时可用                 |
| `h`                  | 前往首页                       |                                      |
| `l`                  | 前往加载游戏页面               |                                      |
| `o`                  | 从您的系统打开新的游戏文件     |                                      |
| `r`                  | 从文件系统刷新当前游戏         | 仅限网站。仅限受支持的浏览器。       |
| `t`                  | 前往地块页面                   | 不适用于游戏编辑页面                 |
| `u`                  | 前往应用信息页面               | 仅限应用。                           |
| `v`                  | 重置地图或股市编辑器的视图     | 仅在地图和股市编辑页面可用           |
| `x`                  | 打开导出菜单                   | 仅限应用。会前往已加载的游戏。       |
| `?`                  | 前往帮助页面                   |                                      |

打开导出菜单后:`p` 导出 PDF,`n` 导出 PNG,`b` 导出 Board18 文件,`o` 打开导出选项。
