# 桌面应用与设置

::: siteonly

## 下载

18xx Maker 也提供 macOS、Windows 和 Linux 的桌面应用。界面与网站相同,但对文件编辑的支持更好,导出选项也更多(参见[从 18xx Maker 应用导出](/docs#从-18xx-maker-应用导出))。如果您正在为自己的游戏制作原型,我们推荐使用它。请从[发布页面](https://github.com/18xx-maker/18xx-maker/releases)下载适合您系统的版本,并像安装其他应用一样安装。

:::

## 应用提供的功能

在应用中,您可以直接从电脑打开游戏文件,应用会监视这些文件,因此您的修改会立即显示(参见[文件](/docs/files#使用-18xx-maker-应用))。导出的文件会写入您选择的文件夹,详见[使用 18xx Maker](/docs#从-18xx-maker-应用导出)。

## 菜单

应用有一个原生菜单:

- **文件**:“打开”(`Ctrl+O`,macOS 上为 `Cmd+O`)打开游戏文件,“打开最近”列出您之前打开过的游戏,“保存”(`Ctrl+S`,macOS 上为 `Cmd+S`)保存您正在编辑的游戏,以及“退出”。
- **编辑**:常用的剪切、复制和粘贴命令。
- **视图**:重新加载、开发者工具、“应用信息”(`Ctrl+U`)、缩放和全屏。
- **窗口**:您系统的窗口命令。
- **帮助**:“文档”(`Ctrl+D`)和“元素”(`Ctrl+E`)。

在 macOS 上,还有以应用命名的菜单,包含“关于”和“退出”。页面内可用的快捷键列在[快捷键](/docs#快捷键)中。

## 应用信息

“应用信息”(在“视图”菜单中,或按 `Ctrl+U`)显示:

- 您正在运行的系统、Electron、Chrome 和 18xx Maker 的版本,
- 更新(见下文),
- 应用保存其运行所需信息的文件:您打开过的游戏、最近的游戏和您最后使用的页面,以及其当前内容。

### 更新

应用在启动时检查新版本。有新版本时,侧边栏会显示“更新到”新版本,应用信息页面的“更新”框中有“下载并安装更新”按钮。应用会安装更新并重新启动。“检查更新”按钮会再次检查。开发构建中已禁用更新。

## 加载游戏

[加载游戏](/games)页面列出您打开过的游戏(“您的游戏”)、内置游戏和测试游戏。“打开文件”按钮用于打开游戏文件。三个筛选器可以缩小列表范围:

- “出版商”和“设计师”:有多位设计师的游戏会列在每位设计师之下,
- “类型”:“内置”或“已加载”。只有在您加载过游戏之后才会显示。

筛选器设为“全部”时不起作用。已加载游戏的垃圾桶图标会让应用忘记该游戏,不会删除您的文件。

## 设置

[设置](/settings)页面(在侧边栏中)包含:

- **主题**:“跟随系统”、“浅色”或“深色”。导出始终为浅色,参见[常见问题](/docs/faq)。
- **语言**:“跟随系统”或可用语言之一。页面会显示检测到的语言,以及您的语言不可用时回退到哪种语言。参见[翻译](/docs/translation)。
- **导出后打开文件夹**:仅限应用。导出完成后,在文件管理器中显示这些文件。
