# 在线游戏

18xx Maker 可以把你打开的游戏放到游戏服务器上,这样你和朋友就能在不同的电脑上,在同一张共享的游戏棋盘上移动地块、标记和市场标记。每一步操作都会在片刻之后出现在所有人的棋盘上。

在线游戏需要一台游戏服务器。由某个人来运行它(参见[运行游戏服务器](/docs/play-server)),并把地址告诉你。

## 在线游戏是什么

在线游戏是一张共享的桌子,而不是游戏引擎。它不了解游戏规则:

- 不会强制执行任何规则。任何玩家都可以把任何地块放到任何六边格上,移动任何标记或市场标记,并从银行拿走任何东西。
- 没有回合顺序。所有人随时都可以操作。
- 托盘(每位玩家和银行持有的东西)是共享的。只拿属于自己的东西全凭自觉。
- 游戏中的任何人都可以撤销任何操作,无论是自己的还是别人的。
- 记录是永久的。每一步操作、每一次撤销以及笔记的每一次修改都会保留在游戏的历史中;撤销只会取消一步操作,不会删除它。

像在真实的桌子上一样玩:在你们的聊天中约定规则以及下一个轮到谁。

## 设置游戏服务器

从侧边栏打开[设置](/settings),在**游戏服务器**中填写服务器地址,例如 `https://play.example.com`。留空则关闭在线游戏。网站可以访问任何 `https://` 服务器;普通的 `http://` 地址只适用于你自己电脑上的服务器(`localhost`)。

## 登录

在侧边栏打开**在线游戏**,选择**使用 Discord 登录**。Discord 会请你允许游戏服务器查看你的名字和你的服务器,然后把你送回 18xx Maker。每位玩家都需要一个 Discord 账号,加入游戏时也需要。

请在同一个标签页中用普通点击开始登录:在新标签页中或用鼠标中键打开**使用 Discord 登录**,会以“登录未完成，请重试”结束。遇到这种情况,重新登录即可。

登录的有效期由服务器决定(除非服务器另有设置,否则为 30 天)。到期后棋盘会提示你的登录已过期:请重新登录。在线游戏页面上的**退出登录**会结束此浏览器上的登录。

## 创建游戏

先加载你想玩的游戏(通过[加载游戏](/games)或打开一个文件),然后进入**在线游戏**并使用**创建游戏**。输入其他玩家看到的名字,然后选择**创建游戏**。

游戏文件、你的配置以及游戏的自定义图片(参见[自定义图片](/docs/games/images))都会上传到服务器,因此其他玩家不需要这个文件。之后修改文件不会改变在线游戏:新版本请创建一局新游戏。

服务器有以下限制:

- 每张图片最大 1 MB。过大的图片会在上传任何内容之前被列出,并且不会创建游戏。
- 服务器还会限制游戏文件的大小、图片的数量和总大小,以及你可以拥有的游戏数量。默认值为 2 MiB、50 张图片、8 MiB 和 50 局游戏,但服务器的运营者可以修改它们。
- 服务器会检查游戏文件。有错误的文件会被拒绝,并列出错误:修正它们(参见 [JSON 模式](/docs/games/schemas))后再试一次。
- 服务器可以只允许某个 Discord 服务器的成员创建游戏。如果你不能创建游戏,仍然可以通过邀请链接加入。

## 邀请玩家

游戏创建后你就是它的所有者。使用棋盘上所有者菜单中的**复制邀请链接**,把链接发给其他玩家。打开链接会显示游戏的标题;玩家登录、输入名字、选择颜色,然后选择**加入游戏**。在线游戏页面上的**你的游戏**会列出你有座位的每一局游戏。

只要游戏处于进行中,任何拥有邀请链接的人都可以加入,所以只把它分享给你的玩家。**新的邀请链接**会生成一个新链接,旧链接随即失效;已经加入的玩家保留他们的座位。

## 游戏棋盘

棋盘一侧是地图(或市场),另一侧是分成标签页的工具。标题旁的徽章显示你是否在线。连接中断时,棋盘会自动重新连接并补上错过的操作。

### 地块

选择一个地块,用**向左旋转**和**向右旋转**转动它,然后点击一个六边格放置它。点击六边格可以选中它,然后旋转或移除上面的地块。每个地块都会显示剩余数量。没有剩余时地块上会注明,仍然放置就会超出供应数量(棋盘会警告你,但不会阻止你)。

### 标记

选择一家公司,然后点击六边格上的一个位置放置它的标记。列表会显示每家公司已放置的标记数量,并在某家公司没有剩余标记时发出警告。点击一个标记可以选中并移除它。

### 市场

选择一家公司,然后点击股票市场的一个格子,把它的标记移到那里。

### 托盘

每位玩家都有一个托盘,银行也有。托盘中放的是公司和地块。新物品来自银行:在托盘上使用**从银行添加**,并用物品旁边的**移动**菜单把它从一个托盘移到另一个托盘。

### 笔记

笔记是游戏中所有人都能看到的一段文字,可用于记录现金、股份数量或棋盘不跟踪的任何其他内容。离开输入框时保存,最多 10,000 个字符。

### 历史与撤销

**历史**标签页列出每一步操作,最新的在最前面,并注明是谁做的。**撤销**会取消仍然有效的最新一步操作,无论是谁做的,历史中会将其划掉。撤销本身也是一步操作:在撤销之后立即再按**撤销**,那一步操作就会恢复。

### 谁在线

标题旁的首字母是此刻在棋盘前的玩家,使用他们座位的颜色。把指针移到上面可以看到名字。

## 所有者控制

游戏的所有者在棋盘上有所有者菜单:

| 菜单项       | 作用                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 复制邀请链接 | 复制邀请链接。                                                               |
| 新的邀请链接 | 生成新的邀请链接。旧链接失效。                                               |
| 观战链接     | 生成并复制观战链接(见下文)。                                                 |
| Discord 通知 | 把游戏的操作发送到 Discord 频道(见下文)。                                    |
| 锁定游戏     | 让游戏变为只读:没有人可以操作,也没有新玩家可以加入。适用于暂停或游戏结束时。 |
| 解锁游戏     | 重新开放已锁定的游戏。                                                       |
| 归档游戏     | 把游戏收起来。它是只读的,并且不计入你可以拥有的游戏数量。                    |
| 重新打开游戏 | 让已归档的游戏重新进行。它会再次计入你的游戏数量。                           |
| 删除游戏     | 为所有人删除该游戏,包括所有操作和笔记。此操作无法撤销,棋盘会先询问你。       |

## 观战链接

观战链接让人们无需登录即可观看游戏,例如直播或没有参与游戏的朋友。观战者可以实时看到棋盘和每一步操作,但不能做任何更改,也不会显示在玩家之中。

在所有者菜单中选择**观战链接**即可生成并复制链接。**新的观战链接**会替换它,**停用观战链接**会关闭它。两者都会立即让旧链接失效,正在用它观战的人也一样。已锁定和已归档的游戏仍然可以观看。服务器对每局游戏的观战人数有限制(默认 50 人);超过后页面会请你稍后再试。

像对待邀请链接一样对待它:任何拥有链接的人都可以观看。

## Discord 通知

所有者可以让游戏的操作发布到 Discord 频道:

1. 在 Discord 中打开频道设置,然后依次进入**整合**、**Webhooks**、**新 Webhook**,并选择**复制 Webhook URL**。
2. 在棋盘上打开所有者菜单中的 **Discord 通知**,粘贴网址并选择**保存**。频道会收到 "Notifications connected"。

从此每一步操作都会变成一行,例如 "Alice placed tile 7 on A1"(消息为英文)。这些行会先收集几秒钟再一起发布,所以繁忙的频道只会收到少量消息而不是很多条。笔记的修改会发布为 "Alice updated the notes",绝不包含其文字。不会提及任何人。

网址保存在服务器上,之后不会再显示,对所有者也一样。要关闭通知,打开 **Discord 通知** 并选择**移除**。在 Discord 中删除该 Webhook 也会让通知停止。

## 桌面应用

在线游戏仅在网站上提供。[桌面应用](/docs/app)会显示在线游戏页面,并提示使用网站。

## 已知限制

- 其他玩家不会立即看到锁定或解锁。锁定后,他们的下一步操作会被拒绝,棋盘变为只读;解锁后,他们要重新加载页面才能看到游戏再次开放。
- 棋盘不会检查游戏的任何内容(参见[在线游戏是什么](#在线游戏是什么))。
- 一局游戏是创建时游戏文件的副本。修改文件需要创建新游戏。
