# 配置面板

配置面板可以更改每个游戏的显示和打印方式:颜色与主题、纸张大小、标记、地块、卡牌和公司执照的布局等等。使用游戏页面工具栏中的“配置”按钮打开它,或在任意页面使用 [?config=true](?config=true)。

## 配置的工作方式

- **配置是全局的。** 这些设置适用于您查看、打印或导出的每个游戏,而不是某一个游戏。它们保存在浏览器的本地存储中(应用以同样的方式保存)。
- **游戏可以有自己的 `config`。** 游戏文件可以带有一个 `config` 字段,包含仅用于该游戏的设置。只有开启“允许游戏配置”(数据部分,默认关闭)时,它才会叠加在您的设置之上。游戏无法设置打印缩放或该设置。当游戏有被忽略的 `config` 时,工具栏会出现一个警告按钮,点击后打开数据部分。面板显示和编辑的是您的设置,而不是这个字段。
- **只保存您的更改。** 其他设置都跟随默认值,因此新版本可以改进您从未改动过的默认值。
- **导出也会使用它。** 导出使用您的配置,但有两个例外:始终使用浅色主题,并按真实尺寸渲染(下面的打印缩放会被忽略)。属于导出的选项请参见[导出选项](/docs/games/exports)。

一个设置的来源按优先级从低到高依次是:内置默认值、提供给命令行的 `config.json`(参见[命令行](/docs/output/cli))、您在面板中的设置、地址中形如 `?config.<设置>=值` 的参数(例如 `?config.cards.layout=die`),最后是游戏自己的 `config`(在允许时)。

## 各部分

面板顶部的下拉菜单用于选择一个部分。每个设置在面板中都有名称和说明,所以这里只是概览。

| 部分       | 更改的内容                                                    |
| ---------- | ------------------------------------------------------------- |
| 颜色与公司 | 颜色主题、公司颜色主题、公司名称和标志、公司覆盖              |
| 导出       | 导出时是否为每种布局生成一张页面                              |
| 布局       | 纸张大小和页边距,以及用于校正打印偏大或偏小的打印机的打印缩放 |
| 标记       | 标记页的布局和尺寸                                            |
| 地图       | 地图显示的内容(坐标、股市、玩家、回合记录)以及页面的切分方式  |
| 地块       | 地块编号、色盲模式、地块页的布局和宽度                        |
| 股市       | 单元格大小、箭头以及股市页显示的内容                          |
| 公司执照   | 公司执照的样式和布局、边框、阶段表和行动顺序、火车卡          |
| 卡牌       | 股份和卡牌样式、尺寸、出血和内边距、骰子卡                    |
| 私有公司   | 私有公司的样式                                                |
| 火车       | 火车的样式以及是否显示图片                                    |
| 货币       | 每种金额的货币写法                                            |
| 字体       | 正文、标题和卡牌字体的字体族、大小、粗细和样式                |
| 数据       | 重置、复制、下载和导入您的配置,以及允许游戏自带的配置         |

## 字体

`fonts` 设置在一处给出某类文字的字体。“字体”部分设置 `body`、`title` 和 `card` 角色的字体族、大小、粗细和样式(卡牌没有大小)。留空的字段表示未设置,并显示它回退到的正文字体;只有您设置的内容才会被保存。其他角色和 `families` 中的名称请在您的 `config.json`、在数据部分导入的 JSON、`?config.fonts...` 参数或游戏文件的 `config` 中设置(编辑面板的[配置标签页](/docs/files)可编辑后者)。当游戏自己设置了 `fonts` 并且开启了“允许游戏配置”时,该部分会提示:以游戏为准。

```json
{
  "fonts": {
    "families": { "fancy": "Georgia, serif" },
    "roles": {
      "body": { "family": "fancy" },
      "title": { "weight": "normal", "style": "italic" },
      "card": { "weight": "bold" }
    }
  }
}
```

- **角色**是一类文字:`body`、`title`、`label`、`revenue`、`token`、`price` 和 `card`。角色可设置 `family`、`size`(数字,使用页面的单位)、`weight`(`normal`、`bold` 或数字)和 `style`(`normal`、`italic` 或 `oblique`)。每项设置都是可选的。角色以 `body` 角色为起点,未设置的项保留文字自己的默认值。
- `family` 可以是 `families` 中的名称、内置的 `display`、`serif` 和 `sans-serif`,或任意 CSS 字体族。系统字体不会嵌入导出文件,参见 [SVG](/docs/output/svg)。
- 目前 `title` 角色设置城市、小镇和场外区域的名称以及独立的六边形名称,`card` 角色设置私有公司卡文字的字体族、粗细和样式。其他角色留给接下来迁移的文字。
- 图块元素或游戏文件的字体字段(如 `info.nameFontSize`)仍然优先于角色,因此不会有游戏自行改变。
- `fonts` 的各部分通过上面的层级合并:游戏自己的 `fonts.roles.title.weight` 和您的 `fonts.roles.title.size` 都会生效,两者设置同一项时游戏优先(开启“允许游戏配置”时)。

## 深层链接

每个部分在地址中都有名称,因此可以直接链接到它:`?config=true&section=tokens` 会在“标记”部分打开面板。名称有 `colors`、`export`、`layout`、`tokens`、`maps`、`tiles`、`stock`(股市)、`charters`、`cards`、`privates`、`trains`、`currency`、`fonts` 和 `data`。未知的名称会打开“颜色与公司”。

## 保存和分享您的配置

“数据”部分将您的更改显示为 `config.json`,您可以下载、复制,或用一个按钮重置为默认值。若要在别处使用某个配置,请导入它:参见[导入 config.json](/docs/files#导入-configjson)。命令行的 `--config` 接受的正是同一个文件。

如果更改后看起来不对,请参见[常见问题](/docs/faq)。
