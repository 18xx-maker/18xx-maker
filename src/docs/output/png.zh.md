# PNG 输出

在 18xx Maker 应用中,您可以浏览任意游戏组件,然后点击导出按钮:

![export button](/images/export-button.png)

> [!NOTE]
> 如果您在网页浏览器中使用 18xx Maker,请注意此按钮并不存在,取而代之的是一个打印图标,它只会打开浏览器的打印菜单。

这会弹出一个带有导出选项的菜单:将整个游戏导出为 PDF 文档、PNG 图片或 Board18 游戏盒。以这种方式导出_会_遵循您在应用中设置的所有设置选项。

地图、股市、发行价、收益和地块清单的图片四周有四分之一英寸的边框(在图片背景中);其他所有图片都恰好裁切为组件的大小。

如果您选择导出整个游戏,应用会让您选择一个文件夹来存放所有文件。文件名_确实_包含游戏名称,但建议您专门为这款游戏创建一个文件夹,以便自己整理。将游戏输出为 PNG 图片会得到_大量_图片。导出完成后,应用会打开生成的文件夹。

导出整个游戏会为每个地块、卡牌、公司执照和标记生成单独的图片。与某家公司直接相关的图片名称中会带有公司简称,并且所有图片都按递增的数字编号(以应对两家公司简称相同的游戏)。

图片始终使用浅色主题渲染。它们以 300 dpi(打印时的分辨率)生成,并带有分辨率信息,因此打开时就是实际尺寸。_导出选项_面板可以选择较低的分辨率(1 到 300 dpi)。游戏文件可以用 `"exports": { "png": { "dpi": 150 } }` 设置分辨率(以及其他导出选项),参见[导出选项](/docs/games/exports):面板会以它作为初始值。

图片只包含组件完整覆盖的像素,因此它可能比以英寸为单位的尺寸乘以分辨率得到的结果少一个像素(一张 2.657 x 1.732 英寸的卡牌在 300 dpi 下为 796 x 518 像素),但边缘绝不会出现半透明或与背景混合的情况。应用和命令行生成的图片完全相同。

## 命令行

> [!IMPORTANT]
> 此工作流需要您拥有应用的源代码,并已按照[本地开发](https://github.com/18xx-maker/18xx-maker/blob/main/DEVELOPMENT.md)的说明完成配置。

运行以下命令可以为每个地块、卡牌、公司执照、标记以及各单页(背景、地图、股市、发行价、收益和地块清单)输出图片:

```bash
pnpm build && pnpm maker export <game> --format png
```

其中 `<game>` 是内置游戏的 id 或游戏文件的路径。文件会写入 `render/<game>`,以游戏标题命名。

图片是为打印而制作的:默认且最高的分辨率是 300 dpi,较低的分辨率用 `--dpi` 设置(1 到 300,`--dpi 301` 会被拒绝)。分辨率会写入文件,因此一张 2.5 x 3.5 英寸的卡牌在图片查看器中会以该尺寸打开,打印出来也是该尺寸。颜色为 sRGB。地图、股市、发行价、收益和地块清单为白色背景,或在使用 `--background transparent` 时为透明;其他所有图片(背景页、卡牌、公司执照、标记和地块)始终是透明的,Board18 游戏盒中的图片也不受此选项影响。超过 2 亿像素的图片(300 dpi 下的超大地图)不会生成,命令会给出提示,您可以调低 `--dpi`。耗时超过两分钟的文档会失败。

```bash
# Only the cards and the map, at 150 dpi
pnpm maker export 1889 --format png --docs cards,map --dpi 150
```

格式、页面和分辨率也可以改在游戏文件中设置,例如 `"exports": { "formats": ["png"], "docs": ["cards", "map"], "png": { "dpi": 150 } }`。命令行参数优先于游戏文件,游戏文件优先于默认值,因此 `pnpm maker export my-game.json --dpi 300` 会以 300 dpi 导出该游戏(面板中的 _PNG 分辨率_以游戏文件的值为初始值,并且可以修改)。游戏文件中超过 300 的分辨率同样是错误(`pnpm validate` 会报告)。所有选项请参见[导出选项](/docs/games/exports)。

请注意,这不会使用浏览器设置页面中的选项,如何使用您的设置请参见 [PDF 输出](/docs/output/pdf)。
