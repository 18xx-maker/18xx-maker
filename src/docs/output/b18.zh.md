# Board18 输出

## 应用

在应用中,导出按钮里有一项可将游戏导出为 Board18 游戏盒,_导出选项_面板则可以设置版本和作者。它们的初始值来自游戏文件的 `exports.b18`(参见[导出选项](/docs/games/exports))。应用会让您选择一个文件夹,用来存放 zip 文件及其中的文件(结构见下文)。无论您为 PNG 图片选择何种分辨率,游戏盒中的图片都是每个单位一个像素。

## 命令行

> [!IMPORTANT]
> 此工作流需要您拥有应用的源代码,并已按照[本地开发](https://github.com/18xx-maker/18xx-maker/blob/main/DEVELOPMENT.md)的说明完成配置。

运行以下命令可以输出可直接用于 Board18 的 zip 文件:

```bash
pnpm build && pnpm maker export <game> --format b18 --b18-version <version> --b18-author <author>
```

其中 `<game>` 是要生成的游戏(内置游戏 id 或游戏文件路径),`<version>` 是在 Board18 上使用的版本标记,`<author>` 是在 Board18 上使用的作者名。例如,下面是我生成 1889 的命令:

```bash
pnpm build && pnpm maker export 1889 --format b18 --b18-version CGG01 --b18-author "Christopher Giroir"
```

`pnpm maker b18 1889 CGG01 "Christopher Giroir"` 的效果相同。如果省略 `--b18-version` 和 `--b18-author`,它们会依次取自游戏文件 `exports` 字段中的 `b18`,例如 `"exports": { "b18": { "version": "CGG01", "author": "Christopher Giroir" } }`,然后是 `maker config` 中的 `b18.author`,最后是 `1.0` 和您的名字。命令行参数始终优先于游戏文件,在面板中输入的内容也是如此。不带版本的 `pnpm maker b18 my-game.json` 会从游戏文件中取得版本。游戏盒中的图片是每个单位一个像素(Board18 所需的尺寸),不会按 `--dpi` 缩放。地图和股市始终为白色,标记和地块为透明,`--background` 不会改变它们。`--variation <n>` 会生成另一个地图变体的游戏盒。

请注意,这不会使用浏览器设置页面中的选项。若要让打印输出与浏览器中看到的完全一致,请打开[设置](?config=true)面板,使用“下载设置”将其保存为文件,然后在上面的命令中加上 `--config my-config.json`。

这会构建应用,然后输出 `render/1889/board18-1889-CGG01.zip` 文件以及一批文件:

```
render/1889
├── board18-1889-CGG01
│   ├── 1889-CGG01
│   │   ├── Brown.png
│   │   ├── Green.png
│   │   ├── Map.png
│   │   ├── Market.png
│   │   ├── Tokens.png
│   │   └── Yellow.png
│   └── 1889-CGG01.json
└── board18-1889-CGG01.zip
```

如果希望命令行记住您的作者名,以免每次都要输入(对于没有设置自己作者的所有游戏),可以运行:

```
pnpm maker config set b18.author "<Your Name>"
```
