# 自定义图片

你可以为游戏添加自己的图片，并在游戏的 JSON 中按名称使用：

- **图标**和**标志**是 [SVG](https://developer.mozilla.org/zh-CN/docs/Web/SVG) 文件。
  图标可用在内置图标出现的任何地方（标记的 `icon`，或图标、地形元素的
  `type`），标志用作标记的 `logo`。
- **火车图片**是 PNG 文件，用作火车的 `image`。

图片以 `custom/<名称>` 的形式使用，例如 `"icon": "custom/star"`。名称就是不含
扩展名的文件名。你的图片不会替换任何内置图片，也不属于游戏的 JSON 文件，所以
分享该文件时不会一并带走。

## 名称

名称以字母或数字开头，之后可以是字母、数字、点、短横线和下划线，最多 64 个
字符。Windows 保留的名称（`con`、`nul`、`com1` 等）不能使用，仅大小写不同的两个
名称视为同一个名称。

## 图片存放位置

- **桌面应用**：在游戏文件旁边的 `<游戏>.assets` 文件夹中，分为 `icons`、
  `logos` 和 `trains` 三个文件夹。游戏 `my-game.json` 的图片位于
  `my-game.assets/icons/star.svg`。你也可以自己把文件放进去。
- **网页应用**：在浏览器的存储中，适用于从你的文件系统打开的游戏，或浏览器为你
  保存的游戏。图片只保存在这台电脑上。
- **内置游戏**不能添加图片。请先保存游戏的副本。

每个游戏最多 200 张图片，总共 10 MB，SVG 最大 512 KB，PNG 最大 2 MB（不超过
4096 乘 4096 像素）。

## 添加图片

在游戏编辑器的**图片**标签页中可以添加、重命名和删除图片，并查看游戏用到了
哪些图片。

打开游戏时，你也可以**把图片拖放到应用上**：

- **PNG** 会作为火车图片添加，名称与文件名相同。
- 对于 **SVG**，会弹出窗口询问它是**图标**还是**标志**，以及它的名称。如果名称
  已存在，你可以替换原图片或给新图片改名。
- 一次最多 20 个文件。其他类型的文件和过大的文件会被报告，其余的仍会添加。
- 单独拖放一个 `.json` 文件仍会作为游戏打开（或作为设置文件应用）。

如果没有打开游戏，或游戏是内置游戏，应用会显示错误，并且不添加任何内容。

## SVG 文件

SVG 文件在显示前会被清理：脚本、动画、指向其他文件的链接和外部图片都会被移除。
内置图标使用的 `color-*` 类在你的 SVG 中同样有效，因此会跟随主题颜色。请将图标和
标志画在正方形内，并以图片中心为中点。
