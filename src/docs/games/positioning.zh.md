# 定位

地块上的每个元素(城市、小镇、数值、标签、图标、地形等)都用同一小组字段来放置。本页按你需要的顺序讲解它们。每一步都在[定位](/elements/positioning)示例页面上实时绘制,并附有对应的 JSON。

1. [坐标](#坐标):0 在哪里,往哪个方向。
2. [放置](#放置):`angle`、`percent`、`x` 和 `y`。
3. [旋转](#旋转):`rotation`、`rotate` 和 `side`。
4. [命名位置](#命名位置):`mid` 和 `align`。
5. [隐藏](#隐藏):`hidden`。
6. [自动定位](#自动定位):不指定时元素放在哪里。
7. [绘制顺序](#绘制顺序):`order`。

给元素设置任何放置字段,都会关闭该元素的自动定位,参见[关闭自动定位](#关闭自动定位)。

## 哪些元素可以定位

下面这些地块元素可以使用本页的字段:`track`、`cities`、`towns`、`centerTowns`、`boomtowns`、`mediumCities`、`labels`、`icons`、`names`、`shapes`、`terrain`、`bridges`、`tunnels`、`tunnelEntrances`、`divides`、`values`、`goods`、`companies`、`tokens`、`routeBonuses`、`industries` 和 `offBoardRevenue`。`track` 和 `divides` 没有 `order`。`borders` 只接受 `side`。

## 坐标

原点是六边格的中心。所有位置都从它开始量,单位的定义是:边的中点距中心 75(六边格从一条边到对边是 150 个单位)。第一个[示例](/elements/positioning#place)标出了 angle 0、90、180 和 270。

- `angle` 是以度为单位的方向,**在屏幕上按顺时针方向**:0 是正下方,90 是左,180 是上,270 是右。
- `percent` 是沿该方向走多远,以 75 个单位为 1:0 是中心,1 是向外 75 个单位。
- `x` 和 `y` 是普通的屏幕单位:`x` 向右,`y` 向下。

角度是屏幕上的方向,不是六边格自身的方向。在地块上和 `horizontal` 地图上,边的中点位于 angle 0、60、120 等处,所以 `percent` 1 正好在边上。在默认的 `vertical` 地图上,六边格旋转了 90 度:angle 0 指向一个角(约 86.6 个单位远),边的中点位于 angle 30、90、150 等处。只有 `mid`(参见[命名位置](#命名位置))会自己跟随这个旋转。

## 放置

- `angle`(-360 到 360,不含端点,默认 0)和 `percent`(0 或更大,默认 0)确定元素位置:先按 `angle` 转向,再按 `percent` 向外走。
- 然后 `x` 和 `y`(默认 0)按普通屏幕单位移动它。它们不会被 `angle` 或任何旋转转动,所以 `"x": 10` 始终是向右 10 个单位。

```json
{
  "labels": [{ "label": "B", "angle": 90, "percent": 0.6, "x": 5 }]
}
```

([示例](/elements/positioning#place))

大于 1 的 `percent` 会越过六边格的边缘。大多数元素会在六边格边缘被裁掉,所以只能看到里面的部分。画在六边格之外的元素不会被裁掉:`names`、外部 `cities`、不是 `background` 的 `shapes`、`bridges`、`tunnels`、`offBoardRevenue`、`industries`、`companies` 和 `routeBonuses`。

## 旋转

- `rotation` 和 `rotate`(-360 到 360,不含端点)让元素在原地顺时针旋转,单位为度。它们是同一个字段的两个名字。只用其中一个:不为 0 的 `rotate` 优先于 `rotation`,`"rotate": 0` 则回退到 `rotation`。它们从不相加。
- 不带 `mid` 的 `side`(1 到 6)把元素旋转 (side - 1) 个六分之一圈,所以边 1 不旋转,边 2 旋转 60 度。它只旋转元素,不移动它。它会与 `rotation` 或 `rotate` 相加。与 `mid` 一起使用时,它改为移动命名点,参见[命名位置](#命名位置)。

```json
{
  "towns": [{ "rotation": 45 }]
}
```

([示例](/elements/positioning#turn))

并非所有东西的旋转方式都一样,因为文字需要保持可读:

| 元素                       | `rotation`               | `rotate` 和 `side` |
| -------------------------- | ------------------------ | ------------------ |
| 小镇、城市(及其名称)、图标 | 旋转                     | 旋转               |
| 标签、数值、地形           | 保持直立,看不到旋转      | 旋转               |
| 标记                       | 转得多一倍(标签文字也是) | 旋转               |

想让标签、数值或地形的文字旋转时,用 `rotate` 或 `side`;要旋转标记,用 `rotate`。标记上的 `"fixed": true` 会让它恰好转动与元素相同的角度,无论你用这三个字段中的哪一个。

与 `mid` 一起使用时,标签、数值和地形的文字保持直立,无论你用哪个字段。

## 命名位置

除了自己计算 `angle` 和 `percent`,元素还可以用 `mid` 指定轨道上的一个点,并用 `align` 使其朝向该处的轨道。它们适用于所有带位置的元素(小镇、centerTown、数值、标签、图标等)。每个点都对应从边 1 开始的轨道,可用 `side` 将其移到其他边。

- `mid` 是某种轨道类型的中点。只有这些全长轨道类型有名字:

  | `mid`      | `angle` | `percent` |
  | ---------- | ------- | --------- |
  | `straight` | 0       | 0         |
  | `sharp`    | 30      | 0.577     |
  | `gentle`   | 60      | 0.268     |

- `side` 与 `mid` 一起使用时,会像从该边开始的轨道一样移动该点,因此边 3 上的 `gentle` 位于 `angle` 180。这是 `side` 唯一会移动元素的地方,没有 `mid` 时它只旋转元素。
- `align` 为 `perpendicular`(垂直)或 `parallel`(平行)于该点处的轨道。它需要 `mid`。`sharp` 上的小镇条为 `perpendicular` 时 `rotation` 是 120,`gentle` 上是 150。`rotate` 和 `rotation` 会作为偏移量叠加。
- 明确给出的 `angle` 或 `percent` 会替换 `mid` 的值,`x` 和 `y` 则从该点开始微调。
- 在 `vertical` 地图上,轨道是旋转 90 度绘制的,`mid` 会随之旋转,所以它落在轨道上。直接写的 `angle` 或 `percent` 不会旋转。

```json
{
  "track": [{ "type": "gentle", "side": 1 }],
  "towns": [{ "mid": "gentle", "align": "perpendicular" }]
}
```

([示例](/elements/positioning#named))

## 隐藏

`hidden`(`true`)不绘制该元素。其他元素保持原位:被隐藏的元素仍然参与[自动定位](#自动定位)的计数,所以第二个标签仍然是第二个标签。

```json
{
  "labels": [{ "label": "B", "hidden": true }, { "label": "NY" }]
}
```

([示例](/elements/positioning#hide))

## 自动定位

自动定位把常见的 95% 的元素放到标准位置,让你不必自己动手。它并不追求面面俱到。它逐个查看每个元素:元素没有 `angle`、`percent`、`rotate`、`rotation`、`side`、`mid`、`align`、`x` 或 `y` 中的任何一个时,就会被自动定位。`hidden` 和 `order` 不算。

| 元素 | 哪些   | 位置(`angle`、`percent`)             | 条件                      |
| ---- | ------ | ------------------------------------ | ------------------------- |
| 数值 | 第一个 | 210、0.7(右上)                       | 总是                      |
| 标签 | 第一个 | 150、0.7(左上)                       | 总是                      |
| 标签 | 第二个 | 270、0.7(右侧)                       | 总是                      |
| 图标 | 全部   | 0、0.6;如果六边格有地形则为 30、0.6  | 六边格有城市或 centerTown |
| 地形 | 全部   | 0、0.7;如果六边格有图标则为 330、0.7 | 六边格有城市或 centerTown |

“第一个”指该数组的第一项,每一项都计数:被隐藏或手动定位的第一个标签仍然占用第一个位置,所以下一个标签是第二个,会移到 270。其他数值和标签不会被移动。多个图标(或多个地形)会全部移到同一个位置并重叠,请给其中除一个以外的都指定位置。

([示例](/elements/positioning#auto))

### 关闭自动定位

要让某个元素不参与自动定位,给它加上一个放置字段。例如添加 `"angle": 0` 就会有效地关闭自动定位,同时让元素保持在六边格中央。这只会关闭该元素的自动定位,六边格上的其他元素仍会被定位。

```json
{
  "cities": [{}],
  "terrain": [{ "type": "mountain", "cost": 60, "angle": 0 }]
}
```

([示例](/elements/positioning#off))

## 绘制顺序

位置只决定元素放在哪里。哪个元素画在哪个之上,由按类型固定的顺序决定(城市,然后是数值、标签、标记、地形、图标等)。要改变它,给元素加上 `order`。它会在该地块所有没有 `order` 的元素之后绘制,`order` 小的先画,它的位置不变。例如,让城市画在数值之上:

```json
{
  "cities": [{ "order": 1 }],
  "values": [{ "value": 30, "x": 0, "y": 0 }]
}
```

([示例](/elements/positioning#order))

- 负数让元素画在所有其他元素之前,`true` 让它最后绘制,`0` 让它画在没有 `order` 的元素之后。
- `order` 相同的元素保持通常的类型顺序。
- 元素始终留在地块边框和编号的同一侧:内部元素不能画到边框之上,画在外面的元素(如外部城市或名称)不能画到边框之下。
- 它可以盖住轨道。
- 轨道、分隔线和边框没有 `order`。

地块元素本身在[地块与六边格](/docs/games/tiles#元素)中说明。
