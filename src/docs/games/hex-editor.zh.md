# 六边格编辑器

编辑面板会绘制六边格,列出其上的内容,并为每个元素提供各自的字段,因此无需编写 JSON 就能制作六边格或板块。**六边格**标签页编辑你选中的地图组(见[文件](/docs/files)),**板块**标签页编辑游戏中的一个板块。两者是同一个编辑器,写入的都是游戏文件中那样的[六边格定义](/docs/games/tiles)。

编辑器只写入你更改的内容。它不认识的键、键的顺序以及你用简写写下的值(只是文本的标签、数字)都保持原样,也不会用默认值填充任何内容。页面会随每次更改而更新,打印和导出的页面不依赖编辑器。

## 绘图

编辑器顶部像地图一样绘制六边格,每条边上有一个按钮,编号与文件中的边相同(1 是未旋转六边格的下边)。点击一条边再点击另一条边,即可绘制它们之间的轨道;再次点击同一条边或按 Escape 可取消。相对的两条边生成 `straight` 轨道,相隔一条边的生成 `sharp` 弯道,相隔两条边的生成 `gentle` 弯道。新轨道会被选中,因此它的字段会显示在下方。

点击绘图中的元素即可选中它。边按钮、元素以及下方的按钮都可以用键盘操作。

## 元素列表

绘图下方的列表为六边格上的每个元素提供一行。选中一行即可编辑该元素,也可以用该行的按钮将它上移或下移(顺序即绘制顺序)、复制或移除。某一类的最后一个元素被移除时,整个列表也会从六边格中移除。底部的“添加元素”可以添加任何有字段的类型的新元素。

## 检查器

选中的元素在检查器中显示其字段。主要字段直接可见,其他字段在“更多字段”之后(`side`、`angle`、`x`、`y`、`percent` 等放置字段也在那里,见[定位](/docs/games/positioning))。“以 JSON 显示”以文本形式显示该元素,表单没有的内容也会保留在那里。字段、名称和说明来自 [JSON 模式](/docs/games/schemas),因此模式中新增的字段无需编辑器的新版本就会出现。

有些元素有比字段更合适的控件:

| 元素                     | 主要字段                             | 控件                      |
| ------------------------ | ------------------------------------ | ------------------------- |
| 轨道                     | type、gauge、width、color            | 选择所连接边的绘图        |
| 城市、中型城市           | size、name、companies                |                           |
| 城镇、中心城镇、繁荣城镇 | name                                 |                           |
| 地图外收益               | name、revenues、rows                 |                           |
| 标签                     | label、size、color                   |                           |
| 边界                     | color、dashed、width                 | 选择所在边的绘图          |
| 分隔线、隧道入口         |                                      | 选择所在边的绘图          |
| 数值、名称、路线奖励     | 文本或数字                           |                           |
| 图标                     | width、noCircle                      | 18xx Maker 所有图标的列表 |
| 地形                     | cost、size                           | 地形类型和图标的列表      |
| 形状、商品、产业、公司   | 文本、颜色、`top`、`bottom`、`label` |                           |
| 桥梁、隧道               | cost、color、textColor               |                           |

类型列表中 18xx Maker 没有的名称,例如你自己的图标名称,会被保留并显示。标记(token)可以是文本、数字或几种对象之一,因此没有字段:请在检查器中以 JSON 编辑。

## 六边格本身

检查器下方是六边格自身的字段:颜色、被切开的六边格的 `half`、`stripeRotation`,以及被移除边界的边(在小图上点击这些边)。在板块标签页中,同一位置是与打印板块有关的字段:数量、打印数量和分组。

## 移动元素

拖动城市、城镇、标签、图标或其他按位置放置的元素即可移动它。拖动会更改它的 `x` 和 `y`(精确到十分位),不论它还由什么来定位;由地图自行放置的元素会得到它当前所在的位置,以免跳动。轨道、边界以及其他位于边上的元素不能拖动:请使用检查器中它们的绘图。

## 撤销和重做

绘图下方的两个按钮,以及 Ctrl 或 Cmd+Z 和 Ctrl 或 Cmd+Shift+Z(也可用 Ctrl 或 Cmd+Y),可撤销和重做在编辑器中所做的更改。一次拖动算一步。焦点在字段中时快捷键不起作用,此时按键属于该字段;每个六边格的历史都会重新开始,切换到 JSON 视图再切回时也会重新开始。

## 只更改组中的一个六边格

地图的一个组是共用同一定义的一列坐标,因此六边格标签页中的更改适用于其中所有六边格,并有提示说明数量。按钮“仅编辑 C11”(带有该六边格的坐标)会把该六边格从组中取出,并为它建立该组的一个独立副本,紧跟在原组之后,以保持各组的绘制顺序。此后你的更改只对该六边格有效。要把六边格放回某个组,请像[文件](/docs/files)中所述,按住 Cmd(Windows 和 Linux 上为 Ctrl)点击地图。如果另一个组也列出了该六边格,会有提示,显示的组是绘制在最上面的那个。

## JSON

表单没有的内容都保留在 JSON 中。使用六边格标签页的“表单”和“JSON”开关可以将该组作为文本修改:文本每次都从该组重新打开。当文本不是有效的组 JSON 时,无法显示表单。
