# 游戏页面

每款游戏对其可打印的每样内容都有一个页面。所有页面共用一个工具栏,每个页面按打印时的样子绘制游戏的相应部分。游戏的地址是 `/games/<游戏 id>`,页面的地址在其后加上页面名称,例如 `/games/18Test/map`。

## 页面

| 页面     | 地址            | 显示                                                       | 游戏文件中需要          |
| -------- | --------------- | ---------------------------------------------------------- | ----------------------- |
| 游戏信息 | (游戏本身)      | 游戏的标题、设计者、出版商、链接、玩家人数、地图预览和统计 | `info`                  |
| 地图     | `map`           | 地图,一次显示一个变体                                      | `map`                   |
| 股市     | `market`        | [股市](/docs/games/market),以及发行价表、图例和回合记录    | `stock.market`          |
| 标记     | `tokens`        | 公司标记和游戏标记的版面                                   | `companies` 或 `tokens` |
| 地块     | `tiles`         | 要打印的每块地块的版面,含各自的数量                        | `tiles`                 |
| 卡牌     | `cards`         | 私有公司、股票、火车和数字牌                               |                         |
| 公司执照 | `charters`      | 每家公司一张公司执照                                       | `companies`             |
| 发行价   | `par`           | 单独的[发行价表](/docs/games/market#发行价表)              | `stock.par.values`      |
| 收益     | `revenue`       | [收益表](/docs/games/market#收益表)                        |                         |
| 地块清单 | `tile-manifest` | 地块列表,含编号和数量                                      | `tiles`                 |
| 背景     | `background`    | 在背景色上重复游戏标题的一页                               |                         |

游戏没有数据的页面在页面菜单中呈灰色,打开其地址会回到游戏信息页面。

### 游戏信息

打开游戏时进入的页面。它显示游戏的标题、设计者、出版商和链接(许可证、购买处、BoardGameGeek 和规则),以及游戏是原型或仍在制作中的提示。第一个地图变体的预览会链接到[地图](#地图)页面。统计列出按颜色和轨距分类的地块、地图大小,以及公司、私有公司、火车、阶段和回合的数量。按钮可从游戏的第一个部分开始编辑、下载游戏文件、从文件重新加载(在浏览器中,针对从电脑加载的游戏),以及移除非内置的游戏。游戏从哪里加载以及如何保存,请参阅[文件](/docs/files)。

### 地图

游戏的地图,含地块、标记、标签和坐标,以及游戏在地图上放置的股市、回合记录和股价变动图例。有多个地图变体的游戏在工具栏中有变体菜单,见[下文](#工具栏)。分页开关会把大地图按纸张大小分成带裁切线的若干页,以便打印后拼接。

### 股市

游戏的股市,含 ledge、图例,以及游戏在其上放置的发行价表、股价变动图例和回合记录。分页会按纸张大小把它分成若干页。有关股市的一切请参阅[股市与发行价表](/docs/games/market)。

### 标记

每家公司的标记版面:股市标记、反面标记、车站标记和额外标记,之后是游戏的 `tokens`。排版、尺寸和数量在[配置面板](?config=true)的“标记”部分。

### 地块

游戏 `tiles` 中的每块地块按其打印数量出现,并按相同颜色和轨距分组(地块可用其 `group` 字段单独成组)。版面布局、地块宽度、间距、裁切边框和定位销在配置的“地块”部分。

### 卡牌

游戏的所有卡牌按页排列:私有公司、每家公司的每张股票、火车,以及从 1 到游戏最大玩家人数的数字牌(其颜色来自 `numberCards`)。卡牌的尺寸和布局在配置的“卡牌”部分。带有 `back` 的列车卡可以双面打印,参见[双面卡牌](/docs/output/pdf#双面卡牌)。

### 公司执照

每家公司一张公司执照,先是大公司,然后是小公司。布局(自由布局,或 3x1 和 3x2 模切布局)、公司执照的尺寸和页面设置在配置的“公司执照”部分。

### 发行价与收益

[发行价表](/docs/games/market#发行价表)和[收益表](/docs/games/market#收益表)单独打印,方便剪下后放在桌上。两者都有分页开关。

### 地块清单

游戏中每块地块的小图,附有编号和数量,按黄色、绿色、棕色和其他颜色各占一列。它用来核对地块是否齐全。

### 背景

用游戏的背景色(`info.background`)铺满的一页,游戏标题倾斜地重复排列其上。

## 工具栏

每个游戏页面左上角的工具栏不会被打印。从左到右:

- **游戏信息**回到游戏的游戏信息页面。
- **配置**打开包含所有打印设置的[配置面板](?config=true)。
- **编辑**(`e`)在页面旁打开编辑面板,请参阅[文件](/docs/files)。
- **刷新**从文件重新加载游戏,仅在网站上、且仅针对从电脑加载的游戏。
- **更改**在游戏与其文件不同时出现。它打开更改页面,历史页面列出本次会话的保存。两者与问题检查一起在[文件](/docs/files)中说明。
- **页面菜单**切换到另一个页面。游戏没有数据的页面无法选择,数字键 `1` 到 `9` 和 `0` 按上表的顺序选择页面,直到背景。
- **打印**(应用中为**导出**)打印页面或导出游戏,请参阅[导出选项](/docs/games/exports)。
- 在地图页面,当游戏定义了多个 `map` 变体时,**变体菜单**选择其中一个。所选变体以 `variation` 出现在地址中,所以 `?variation=1` 是第二个。
- 在卡牌页面,**筛选**菜单隐藏一类卡牌:私有公司、股票、火车或数字牌。
- 在地图、股市、发行价和收益页面,**分页**开关(`n`)把页面拆分以便打印在纸上,请参阅[打印游戏](/docs)。

标记、地块、卡牌和公司执照页面总是按页排列,没有分页开关。Board18 页面不显示工具栏。

## 地址

页面的状态保存在其地址中,因此可以分享或收藏:

- `?paginated=true` 以分页方式显示地图、股市、发行价或收益页面。
- `?variation=1` 显示第二个地图变体(0 是第一个)。
- `?hidePrivates=true`、`?hideShares=true`、`?hideTrains=true` 和 `?hideNumbers=true` 在卡牌页面隐藏一类卡牌。可用 `&` 组合,例如 `/games/18Test/cards?hidePrivates=true&hideTrains=true`。

配置面板和编辑面板的地址请参阅[文件](/docs/files)。

## 单个项目

公司执照、标记、卡牌和地块也有只显示单个项目的页面,供单个图片导出使用,不在页面菜单中。请参阅 [PNG 输出](/docs/output/png)。

## Board18 页面

`/games/<id>/b18/map`、`/games/<id>/b18/tiles/<颜色>` 和 `/games/<id>/b18/tokens` 是 Board18 导出所截取的页面:Board18 所要求的尺寸和方向的地图和某一颜色的地块,以及标记。它们没有工具栏。请参阅 [Board18 输出](/docs/output/b18)。
