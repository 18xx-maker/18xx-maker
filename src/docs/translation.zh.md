# 18xx Maker 翻译

本工具的界面和文档都可以翻译成其他语言。如果您能帮忙翻译任何内容,请与我们联系!

## 机器翻译

界面以及所有文档页面的德语(`de`)和简体中文(`zh`)翻译均由 AI 生成,而非母语人士完成,因此可能存在错误或措辞生硬之处,尤其是 18xx 和桌游术语(地块、标记、公司执照、发行价等)。非常欢迎提交修正它们的 Pull Request,无论是一个词还是整个文件。

## 界面

界面翻译的权威来源是主文件 [src/locales/en.json](https://github.com/18xx-maker/18xx-maker/blob/main/src/locales/en.json)。如果您想翻译成其他语言,只需提交一个 Pull Request,附上翻译成另一种语言的内容即可。

## 文档

文档页面(包括本页)以 [markdown](https://www.markdownguide.org/) 文件的形式存放在[代码仓库中](https://github.com/18xx-maker/18xx-maker/tree/main/src/docs)。文件名格式为 `<slug>.<language>.md`。`en` 语言的文件应视为权威来源。若要添加其他语言,请提交 Pull Request,并添加其他语言的文件。
